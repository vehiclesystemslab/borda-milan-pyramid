## Overview

This repository/deposit contains Version 1.1 of *The Borda Milan Pyramid and the VEHICLE Formula-as-Architecture: A Projection-Governed Framework for Complex Relational Systems*.

The work presents the Borda Milan Pyramid as an architectural synthesis of the VEHICLE research framework. VEHICLE is proposed as a projection-governed relational architecture for studying complex systems composed of internally structured nodes.

Each node is represented through an E.I.A.R.(V) state:

- **E** — Orientation / structural spin
- **I** — Information density
- **A** — Active coupling
- **R** — Relational compatibility
- **V** — Verification-projection governance

The framework combines graph-based representation, dual-layer tension, internal coherence, projection-governed correction, operational attractor regimes, and future attractor discovery.

## Main Contribution

The central contribution of this work is architectural integration.

The Borda Milan Pyramid organizes the transition from:

1. an observed scientific domain,
2. relational graph conversion,
3. internally structured VEHICLE nodes,
4. dual-layer tension,
5. projection-governed correction,
6. operational attractor classification,
7. future attractor discovery,
8. scientific decision support.

This version refines the original architecture by improving mathematical notation, clarifying the projection-governed formulation, adding a symbol table, documenting limitations, and preparing citation metadata for reproducibility and academic review.
